# Sources et licences à conserver visibles

OpenStreetMap : données ODbL, attribution requise.
OpenFreeMap : fond cartographique basé sur OpenStreetMap, attribution affichée par MapLibre.
transport.data.gouv.fr : catalogue public des données de mobilité, licences indiquées par chaque producteur.
geo.api.gouv.fr : API publique de découpage administratif.
Service-Public.fr : liens vers les services officiels.
France Évasion Régions / DATAtourisme : événements selon les conditions de la source et Licence Ouverte associée.

Les contributions utilisateurs restent identifiées comme « Communauté » et ne remplacent pas silencieusement une donnée officielle.
